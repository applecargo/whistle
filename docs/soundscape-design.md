# Whistle 사운드 설계 · Pd 작업 안내

편집자가 12×12 격자에 **번짐(풀), 흐름(물), 거침(바위)**을 놓으면 앱은 3D 장면을 만드는 데 쓴 같은 격자 데이터에서 풀밭·수역·물길을 찾는다. 게임은 플레이어의 위치를, UWB는 전시장의 미터 좌표를 격자로 바꾼 위치를 같은 계산에 넣는다. Pd는 그 결과로 타격의 리듬, 물의 잔향, 고리의 숨결을 합성한다.

## 격자가 소리가 되는 규칙

| 세계에서 바꾼 것 | 들리는 변화 | Pd에서 수정할 곳 |
| --- | --- | --- |
| 풀밭을 만든다 | 가장 짙은 풀 타일이 타격의 출발점이 된다. 편집할 때 한 번, 게임·UWB 청취 중에는 2.1초마다 세 번 울린다. | [타격 음색](../audio/patches/stone-knock-voice.pd) · [리듬과 믹스](../audio/patches/world-resonance-live.pd) |
| 물을 잇거나 물가에 바위를 놓는다 | 풀 타격이 물의 공명 회로를 울린다. 물이 한 수역으로 모일수록 잔향이 길고, 물과 변을 맞댄 마른 바위가 하나라도 있으면 짧아진다. | [물의 잔향과 바위 감쇠](../audio/patches/water-resonator.pd) |
| 풀에서 물길을 잇는다 | 상하좌우로 두 칸 이상 이어진 열린 물길에서 짧은 메아리가 돌아온다. 빈 타일을 둘러싼 닫힌 고리에 닿으면, 같은 타격에 맞춰 필터를 거친 노이즈가 숨결처럼 부풀었다 사라진다. 물길 길이는 도착 시간, 고리 안 빈칸 수는 숨결 길이를 정한다. | [메아리·숨결](../audio/patches/water-loop-return.pd) |

예를 들어 풀에서 세 칸 떨어진 고리가 빈칸 하나를 감싸면, 타격 **216ms 뒤**에 숨결이 시작된다. 현재 Pd 설정은 물길 한 칸마다 지연을 42ms씩 더하고(기본 90ms, 최대 24칸), 안쪽 빈칸 한 칸마다 숨결의 감쇠를 90ms씩 늘린다(기본 390ms, 최대 8칸).

풀과 고리 **사이**에서 들으면 두 소리의 자리가 구분된다. 타격은 풀 타일에서, 숨결은 도달한 고리 안 빈칸들의 중심에서 들린다. 각각 가까울수록 커지고, 왼쪽에 있으면 왼쪽 채널이 커진다. 게임은 플레이어의 시선 방향을 따르고 가상 UWB는 격자 위쪽(−Z)을 정면으로 쓴다. 일반 물 잔향과 열린 물길의 메아리는 양쪽 채널에 함께 보낸다. [거리·방향 계산](../lib/audio/world-resonance.ts) · [스테레오 패닝](../audio/patches/resonance-pan.pd)

## Pd가 받는 값

`[r $1-whistle-resonance]`에서 아래 순서로 숫자 리스트를 받는다. 앞의 여섯 값은 음량과 세계 상태, 뒤의 세 값은 두 음원의 공간화에 쓰인다.

| 순서 | 값 | 단위와 의미 |
| --- | --- | --- |
| 1–2 | 풀 타격 음량, 물 잔향 음량 | 0~1. 풀까지의 거리로 감쇠하고 물이 없으면 둘째 값은 0 |
| 3–4 | 수역 연결도, 물가 바위 유무 | 0~1, 0 또는 1 |
| 5–6 | 물길 거리, 고리 내부 면적 | 격자 칸 수. 닿는 고리가 없으면 면적은 0 |
| 7–9 | 풀 패닝, 숨결 음량, 숨결 패닝 | 패닝은 −1(왼쪽)~+1(오른쪽), 음량은 0~1. 고리가 열리면 8·9번을 생략해 남은 숨결이 원래 자리에서 잦아든다. |

`[r $1-whistle-resonance-control]`은 **0 정지 / 1 반복 시작 / 2 편집 타격 한 번**이다. 플레이어나 태그가 움직이면 음량과 패닝을 갱신하고, 타격 시점은 Pd가 정한다.

다른 소리는 별도 입력을 쓴다. `whistle-edit`는 편집한 칸의 좌표·겹침 강도, `whistle-player`는 플레이어 위치·주변 재질·보행 상태, `whistle-event`는 게임 규칙음의 주파수·음량·패닝을 전달한다. 일반 게임의 업로드 음원은 거리와 방향을 반영한 스테레오 신호로 `adc~ 1 2`에 들어간다. UWB 보드 높이는 별도로 수신하며 현재 공간화에는 X·Z만 쓴다.

## 수정하고 들어보기

1. 위 표의 패치를 수정한다. 게임과 UWB는 pd4web 엔진에서 [world-audio.pd](../audio/patches/world-audio.pd)를 연다. 이 패치가 풀·물의 공명과 [배치 음원 효과](../audio/patches/placed-sound-fx.pd)를 스테레오로 합친다. 게임의 편집·플레이어·이벤트와 주변 영역 패치는 각자의 슬롯에서 재생한다.
2. 패치를 저장하고 프로젝트 루트에서 `npm run audio:build`를 실행한 뒤 두 페이지를 새로고침한다. 패치 출력까지 검사하려면 `npm run test:soundscape`를 실행한다.
3. 원래 격자에 **왼쪽 풀 → 물길 → 오른쪽 고리**를 놓는다. 게임에서 둘 사이에 서서 격자 위쪽을 보고, 같은 브라우저의 UWB 페이지에서 **Whistle 3D → 가상 좌표 직접 입력 → 오디오 시작**을 선택한다. 평면도의 같은 위치에서 왼쪽 타격과 오른쪽 숨결을 비교한다. [따라 놓을 격자 예시](../audio/README.md#물길-끝에서-돌아오는-숨결)
