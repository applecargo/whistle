# 오브제 관찰 화면 3개

1. **설치와 구도.** 세 모니터를 각각 M1–M3로 지정한다. 실제 설치 위치를 가상 격자에 대응시키고 그 근처 풀밭, 웅덩이, 나무, 돌밭을 바라본다. 같은 웅덩이를 서로 다른 위치에서 볼 수 있다. 사진·글을 배치한 자리와 높인 땅도 대상이 된다. 현재 렌더링하는 세계의 지형과 날씨를 사용한다.
2. **무엇을 보여줄지.** 첫 연결에서는 모니터에 가장 가까운 대상을 고른다. 근처 칸이 비어 있으면 시선을 더 먼 대상까지 연다. 가까운 대상은 표면이 크게 보이고 먼 대상은 주변 지형과 함께 보인다. 한 번 고른 대상은 유지하되, 사라지거나 다른 대상이 한 칸 이상 더 가까워지면 부드럽게 새 구도로 이동한다.
3. **관객이 다가올 때.** 실측 좌우 위치로 카메라를 소폭 회전한다. 바라볼 대상은 타일 편집과 모니터 배치로 결정한다. 음원 순위, 음량, 재생 시점은 구도 결정에 사용하지 않는다.
4. **조정과 확인.** 전시 화면 메뉴에서 모니터별 X·Z와 정면을 지정해 해당 창을 연다. 기본값은 6×6 m 예시 배치다. UWB 실험실에서 다른 공간 매핑을 적용하면 같은 원점·크기·회전을 관찰 창에도 적용한다. 창을 열어 둔 채 대상을 추가·삭제하고 모니터 좌우로 가상 좌표를 옮겨 구도를 확인할 수 있다.

## 설치와 접속

메인 편집기와 보조 창은 한 PC의 같은 브라우저 프로필과 서버 주소를 사용한다. 전시 화면 메뉴는 `?display=monitors`, 각 출력은 `?display=M1`부터 `?display=M3`까지다. 메인 한 창이 현재 세계를 보내고 보조 창은 창마다 카메라 하나를 그린다. 미니디스플레이 출력은 최대 30 fps, 장치 픽셀 배율 최대 1로 설정한다.

**UWB 모니터 설치 위치**에서 각 모니터의 바닥 투영 중심 X·Z를 미터로 넣는다. 정면은 화면에서 관객 쪽으로 나오는 방향이며 +Z가 0°, +X가 90°다. **이 배치로 화면 열기**를 누르고 열린 창을 미니디스플레이로 옮긴다. 설치 좌표와 방향은 주소에 들어간다. 방의 매핑 사각형 바깥에 설치한 모니터는 가장 가까운 맵 가장자리를 관찰 기준으로 삼는다.

**UWB 관객 위치 테스트**에서 수동 입력 또는 실제 PC 수신기를 선택한다. 정면 1.8 m 안에서는 관객이 다가오는 방향으로 좌우 최대 10°, 위로 최대 3° 이동한다. 수신이 끊기면 기본 각도로 돌아온다. 사운드는 기존 위치 매핑을 사용한다.
