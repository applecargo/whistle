# 오브제 관찰 화면 3개

1. **설치와 구도.** 세 모니터를 각각 M1–M3로 지정한다. 실제 설치 위치를 가상 격자에 대응시키고 그 근처 풀밭, 웅덩이, 나무, 돌밭을 바라본다. 같은 웅덩이를 서로 다른 위치에서 볼 수 있다. 사진·글을 배치한 자리와 높인 땅도 대상이 된다. 현재 렌더링하는 세계의 지형과 날씨를 사용한다.
2. **무엇을 보여줄지.** 첫 연결에서는 모니터에 가장 가까운 대상을 고른다. 근처 칸이 비어 있으면 시선을 더 먼 대상까지 연다. 가까운 대상은 표면이 크게 보이고 먼 대상은 주변 지형과 함께 보인다. 한 번 고른 대상은 유지하되, 사라지거나 다른 대상이 한 칸 이상 더 가까워지면 부드럽게 새 구도로 이동한다.
3. **관객이 다가올 때.** 실측 좌우 위치로 카메라를 소폭 회전한다. 바라볼 대상은 타일 편집과 모니터 배치로 결정한다. 음원 순위, 음량, 재생 시점은 구도 결정에 사용하지 않는다.
4. **조정과 확인.** 전시 화면 메뉴에서 모니터별 X·Z와 정면을 지정해 해당 창을 연다. 기본값은 6×6 m 예시 배치다. UWB 실험실에서 다른 공간 매핑을 적용하면 같은 원점·크기·회전을 관찰 창에도 적용한다. 창을 열어 둔 채 대상을 추가·삭제하고 모니터 좌우로 가상 좌표를 옮겨 구도를 확인할 수 있다.

## 설치와 접속

- **키오스크 + 별도 브라우저 또는 PC** — 키오스크의 **맵 보내기**가 연결되면 **전시 화면 → M1**을 연다. 메뉴는 키오스크에 설정한 수신기 주소를 관찰 창에 전달한다. 수신기의 `/world`가 최신 맵과 매핑을 보내고, `/`가 태그 위치를 보낸다. 관찰 창을 다시 열어도 최신 맵을 받는다.
- **직접 접속** — 같은 Mac의 별도 프로필에서 `http://127.0.0.1:5193/whistle/?display=M1`을 연다. 같은 프로필의 편집기가 없으면 페이지를 제공한 호스트의 5194번 수신기에 연결한다. 다른 수신기 포트를 쓰거나 맵 출처를 고정하려면 `&bridge=ws://서버주소:포트`를 붙인다. 다른 기기에서는 페이지와 수신기 주소 모두 서버의 LAN 주소를 사용한다.
- **현장 없이 확인** — 별도 포트로 `npm run uwb:demo -- --ws-port 5294 --udp-port 5295`를 실행한다. 테스트용 브라우저 프로필에서 키오스크의 수신기를 `ws://127.0.0.1:5294`로 정하고 다른 프로필에서 `?display=M1&bridge=ws://127.0.0.1:5294`를 연다. 가상 태그가 모니터 정면 1.8m 안에 들어오면 시선이 움직인다. 여러 태그가 가까울 때는 현재 태그보다 0.2m 이상 가까운 태그로 전환한다.
- **메인 편집기와 같은 프로필** — 수신기를 지정하지 않은 M1~M3는 같은 브라우저의 열린 편집기에 우선 연결한다. 기존 A1~C3 조각 화면도 이 로컬 연결을 사용한다.

**UWB 모니터 설치 위치**에서 각 모니터의 바닥 투영 중심 X·Z를 미터로 넣는다. 정면은 화면에서 관객 쪽으로 나오는 방향이며 +Z가 0°, +X가 90°다. **이 배치로 화면 열기**를 누르고 열린 창을 미니디스플레이로 옮긴다. 설치 좌표와 방향은 주소에 들어간다. 방의 매핑 사각형 바깥에 설치한 모니터는 가장 가까운 맵 가장자리를 관찰 기준으로 삼는다.

같은 프로필의 메인 편집기를 사용할 때는 **UWB 관객 위치 테스트**에서 수동 입력 또는 실제 PC 수신기를 선택한다. 정면 1.8 m 안에서는 관객이 다가오는 방향으로 좌우 최대 10°, 위로 최대 3° 이동한다. 수신이 끊기면 기본 각도로 돌아온다. 사운드는 기존 위치 매핑을 사용한다.

파이에서 기존 M1·M3 구도를 유지하려면 `/whistle/monitor-proximity/?display=M3&framing=default&mx=6.47&mz=4.05&face=23`처럼 연다. 이 모드에서 `mx`, `mz`, `face`는 관객 감지에만 쓰인다. 사용하는 수신기가 별도 호스트라면 기존처럼 `bridge`를 지정한다.

## 이전 9구역 조각 화면

`?display=A1`부터 `?display=C3`까지는 고정 사선 구도로 자른 지형, 등고선, 최근 30초의 보행 흔적을 볼 때 사용한다. B3에서 B2로 건너면 두 조각의 경계에서 흔적이 이어진다.

## Windows 키오스크 두 화면

- Windows 전시 계정으로 로그인한 상태에서 웹 서버를 시작하면 Chrome이 기본 모니터에 편집 채널을 전체 화면으로 연다. 왼쪽은 재료 메뉴, 중앙은 격자, 오른쪽은 수신 상태와 T0~T3 위치다.
- Windows 디스플레이 설정에서 **확장**을 선택한다. 두 번째 화면을 연결하면 해당 화면에 같은 맵의 3D 전경이 열린다. 화면이 한 대면 편집 채널만 표시한다.
- 편집 채널은 `/whistle/kiosk/?channel=editor`, 3D 채널은 `/whistle/kiosk/?channel=scene`이다. 같은 Chrome 프로필에서는 편집기가 미리보기 상태를 두 번째 창에 직접 보내므로 타일을 놓을 때의 파동과 연결 발판까지 함께 표시된다. 다른 기기에서 3D 주소를 열면 UWB 수신기의 `/world`로 맵을 받는다. 상단 메뉴와 매핑 설정을 사용하는 관리 페이지는 `/whistle/kiosk/`다.
- 브라우저 창을 열지 않고 Windows 웹 서버만 실행하려면 해당 프로세스에 `WHISTLE_KIOSK=0`을 설정한다.
